This module enforces SC-12, SC-13, SC-28, AU-11, CM-6, and AC-3 on a GCS bucket: the organization owns the CMEK (not Google-managed defaults), encryption at rest uses a 90-day rotating key, versioning and retention preserve objects, required labels and bucket settings are applied as a non-bypassable configuration floor, and uniform bucket-level access with public access prevention restricts who can reach the data.
